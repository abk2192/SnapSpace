Keyboard Shortcuts
  • Ctrl + K : Search all projects
  • Ctrl + S : Export project
  • Ctrl + O : Import project
  • Alt + N : Add new note
  • Alt + T : Add new tab
  • Alt + R : Rename tab
  • Alt + F : Add new field to current note
  • Alt + H : Open Help & Shortcuts
Tips
  • Expand/Collapse: Use the Expand All / Collapse All buttons in the header. Safely double-click or drag-highlight tags without opening the note.
  • Drag & Drop: Reorder projects, tabs, and notes by dragging them.
  • Images: Paste screenshots directly into the Notes area (Ctrl+V). Double-click to zoom.
  • Cross-Project Move: Click the Move icon on any item to send it to another project.
